# 🧮 Tabuada em JavaScript

Uma aplicação web simples para gerar a tabuada de um número escolhido pelo usuário. Desenvolvida com HTML5, CSS3 e JavaScript, permite definir até qual multiplicador os cálculos serão exibidos.

## ✨ Funcionalidades

- 🔢 Informar o número para gerar a tabuada
- 🎯 Escolher até qual multiplicador calcular
- 🧮 Calcular e exibir os resultados dinamicamente na página
- 📝 Atualizar o título da tabela com o número informado
- 🎨 Interface estilizada com CSS

## 🚀 Tecnologias Utilizadas

- **HTML5** — estrutura da página e formulário de entrada
- **CSS3** — estilos e apresentação visual
- **JavaScript** — captura dos dados do formulário, cálculo da tabuada e atualização do DOM

## 💻 Como Executar

Não é necessário instalar dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/FLAfonsso/Tabuada-JS.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Tabuada-JS
   ```

3. Abra o arquivo `index.html` no navegador.

## 🧑‍💻 Como Utilizar

1. Informe o número no campo **Tabuada do**.
2. Escolha no campo **Multiplicar até** o limite dos multiplicadores.
3. Clique em **Calcular** para visualizar a tabuada gerada na página.
